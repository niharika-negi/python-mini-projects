# Employee Payroll Management System Using Python

## About the Project

This project is developed using Python to calculate employee salaries and generate payroll reports.

It uses Object-Oriented Programming (OOP) concepts to store employee details, calculate salary components, and determine the final net salary.

## Features

* Create employee objects.
* Store employee ID, name, and basic salary.
* Calculate House Rent Allowance (HRA).
* Calculate Dearness Allowance (DA).
* Calculate Provident Fund (PF) deduction.
* Calculate net salary.
* Display complete employee payroll reports.
* Manage multiple employees using a list of objects.
* Validate negative basic salary values.

## Technologies Used

* Python
* Jupyter Notebook

## Concepts Used

* Classes and Objects
* Constructors (`__init__`)
* Instance Variables (`self`)
* Instance Methods
* Arithmetic Operations
* Conditional Statements
* Lists and Loops
* Exception Handling (`ValueError`)

## Salary Calculation Formula

* HRA = Basic Salary × 20%
* DA = Basic Salary × 10%
* PF = Basic Salary × 12%
* Net Salary = Basic Salary + HRA + DA − PF

*Note: These percentages are used for educational purposes and may not reflect actual company payroll policies.*

## How to Run

1. Download or clone this repository.
2. Open `employee_payroll_system.ipynb` in Jupyter Notebook.
3. Run the code cells in order.
4. View the generated employee payroll reports.
