# Bank Account Management System Using Python

## About the Project

This project is developed using Python to simulate basic banking operations such as depositing money, withdrawing money, and checking the current account balance.

It uses Object-Oriented Programming (OOP) concepts to manage account holder details and maintain individual account balances.

## Project Features

* Create bank account objects.
* Initialize account holder details using a constructor.
* Set the opening account balance.
* Deposit money into an account.
* Withdraw money from an account.
* Check the current account balance.
* Validate deposit and withdrawal amounts.
* Prevent withdrawals exceeding the available balance.
* Maintain separate balances for multiple accounts.

## Technologies Used

* Jupyter Notebook

## Concepts Used

## How to Run

1. Download or clone this repository.
2. Open `bank_account_management.ipynb` in Jupyter Notebook.
3. Run the code cells in order.
4. Test the deposit, withdrawal, and balance-checking operations.
