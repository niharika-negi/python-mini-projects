# Student Management System Using Python

## About the Project

This project is developed using Python to manage student information and generate student performance reports.

It uses Object-Oriented Programming (OOP) concepts to store student details, calculate total and average marks, assign grades, and display complete student reports.

## Features

* Create student objects.
* Initialize student details using a constructor.
* Store student names, roll numbers, and subject marks.
* Calculate total marks and average marks.
* Calculate student grades based on average marks.
* Display complete student reports.
* Manage multiple students using a list of objects.

## Technologies Used

* Python
* Jupyter Notebook

## Concepts Used

* Classes and Objects
* Constructors (`__init__`)
* Instance Variables (`self`)
* Methods
* Lists
* Conditional Statements (`if-elif-else`)
* Loops
* Built-in Functions (`sum()` and `len()`)

## Grading Criteria

| Average Marks | Grade |

| 75–89.99      | B     |
| 60–74.99      | C     |
| 40–59.99      | D     |
| Below 40      | F     |

*Note: These grading criteria are defined for demonstration purposes.*

## How to Run

1. Download or clone this repository.
2. Open `student_management_system.ipynb` in Jupyter Notebook.
3. Run the code cells in order.
4. View the student reports.
